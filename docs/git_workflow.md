# Flujo Git del proyecto

Se trabajara con 3 ramas principales:

- `desa`: rama de desarrollo activo.
- `pre`: rama de preproduccion (validacion/QA).
- `pro`: rama de produccion.

## Regla de promocion

1. Desarrollo diario en `desa`.
2. Cuando una fase esta estable, se integra a `pre`.
3. Cuando `pre` esta validada, se integra a `pro`.

## Estado actual

- Ramas creadas localmente: `desa`, `pre`, `pro`.
- Rama de trabajo activa: `desa`.
